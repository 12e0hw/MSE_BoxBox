# BoxBox
2026-1 Media Software Engineering Team Project

Unity로 제작한 2D 탑다운 로컬 협동 물류 게임입니다.

2명의 플레이어가 제한 시간 내에 컨베이어 벨트에서 무작위로 생성되는 물류 박스를 옮기고, 물자 종류에 맞는 트럭에 적재하여 목표 점수를 달성하는 방식으로 진행됩니다. 

플레이어는 맵 곳곳의 장애물을 피하면서 서로 역할을 나누고 동선을 조율해야 하며, 박스 크기에 따라 점수가 달라져 전략적인 판단이 필요합니다. 각 스테이지는 제한 시간 안에 목표 점수를 달성하면 클리어됩니다.

### Tech Stack

- Engine: Unity
- Language: C#, Java
- Framework: Spring Boot
- Database: H2 Database
- API: Weather API
- Platform: Windows
